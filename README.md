Twin Lanterns is an original spot-the-difference game for the desktop browser: two near-identical picture-book scenes side by side, three levels (Lantern Lane, Harbor Dusk, Garden Festival), 24 differences to hunt against the clock, with markers on every find, a big counter of how many remain, hints, keyboard play and generated chimes. It runs offline from static files with no network request.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
python3 -m http.server 8765 --directory game --bind 127.0.0.1
# then open http://127.0.0.1:8765/index.html in Chrome
```
